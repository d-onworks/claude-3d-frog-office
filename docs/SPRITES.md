# 캐릭터 그림(스프라이트) 바꾸기

## 그림 파일 규격

- 위치: `web/office/<종><꼬리>.webp` 와 짝 `web/office/<종><꼬리>-key.webp`
  - 종 = `frog`(개구리) · `capy`(카피바라)
  - 꼬리 = `""`(기본) · `2` · `3` · `mini`(서브에이전트) · `walk`(걷기) · `phone`(휴대폰)
- 시트 하나 = 가로 한 줄(걷기 시트는 20칸, 나머지는 8칸). 칸 크기 = `OFFICE_ATLAS.cellW × cellH`(지금 220×280). 모든 시트가 같은 칸 크기여야 한다.
- 캐릭터 **발끝 = 칸 아래 끝**, 가로 가운데 정렬. 배경은 투명.
- `-key` 그림 = 프로젝트 색으로 칠할 부분(모자·가디건)만 불투명한 마스크. 화면이 이 마스크에 색을 채워 본그림에 곱한다.

`web/office-atlas.js`(자동 생성, 손으로 고치지 않는다):

| 칸 | 뜻 |
|---|---|
| `cellW`, `cellH` | 칸 크기(픽셀) |
| `stand` | 서 있는 기본 자세의 키(픽셀) — 화면 크기를 이걸로 맞춘다 |
| `heights[시트][칸]` | 칸마다 키 비율(서 있는 키 = 1). 이름표·말풍선·누르기 상자 높이에 쓴다 |
| `strides[종]` | 걷기 그림 한 장마다 몸이 나아가는 거리(칸 픽셀). 어른은 걸은 거리로 장을 넘겨 발이 바닥에서 안 미끄러진다 |
| `chairs[]` | 의자 등받이 상자(`box`)·앉는 점(`seat`)·꼬마를 올려 앉히는 양(`kid`) — 사무실 그림과 짝 |

## 지금 걷기 시트(`frogwalk`·`capywalk`) 칸 배치

| 칸 | 자세 이름(POSES) | 모습 |
|---|---|---|
| 0~7 | `stepF0`~`stepF7` | 어른 앞걸음 한 걸음 8장(얼굴 보임, 왼쪽을 봄) |
| 8~15 | `stepB0`~`stepB7` | 어른 뒷걸음 한 걸음 8장(등 보임, 오른쪽을 봄) |
| 16, 17 | `mWalk`, `mWalk2` | 서브에이전트 앞걸음 |
| 18, 19 | `mBack`, `mBack2` | 서브에이전트 뒷걸음 |

`standBack`(등 보이고 서 있기 — 서버실 랙·커피 머신 앞)은 걷기 시트가 아니라 `3` 시트 3번 칸이다.

## 걷기 그림 교체 순서

1. **덮어쓸 파일** — `web/office/frogwalk.webp`, `frogwalk-key.webp`, `capywalk.webp`, `capywalk-key.webp`, `web/office-atlas.js`.
   아틀라스의 `heights.frogwalk`·`heights.capywalk` 가 새 그림과 맞아야 한다. 칸 크기가 바뀌면 다른 시트도 모두 같은 크기로 다시 만든다.
2. **칸 배치·칸 수가 그대로면 코드 수정 없음.** 바뀌었으면 `web/office-view.js` 맨 위만 고친다.
   - 어른 걷기 장 수 `WALK_N`(지금 8) — 앞걸음은 칸 0~N-1, 뒷걸음은 칸 N~2N-1 로 자동으로 이어진다.
   - `POSES` 의 서브에이전트 걷기(`mWalk*`·`mBack*`) — `["walk", 칸 번호, 원래 보는 쪽]`.
     원래 보는 쪽 = 그림 속 캐릭터가 왼쪽을 보면 `-1`, 오른쪽이면 `1`. 틀리면 뒷걸음질처럼 보인다.
   - 걷기 자세를 고르는 코드는 `walkPose()` 한 곳뿐이다. 어른은 걸은 거리 ÷ `strides`, 서브에이전트는 걸음 위상으로 장을 넘긴다.
3. `standBack` 이 등 보이고 다리가 모인 칸을 가리키는지 본다.

## 확인

`npm run demo` 로 데모 화면을 열고(주소 뒤 `?debug` 를 붙이면 통로·벽·자리가 보인다), 아래를 눈으로 본다.

- 걸을 때 발이 그림자 타원 위에 있다(뜨거나 파묻히지 않는다).
- 옆으로 걸을 때 얼굴 방향 = 걷는 방향, 위(화면 안쪽)로 걸을 때 뒷모습.
- 칸이 바뀔 때 키가 튀지 않는다(`heights` 확인).
- 프로젝트 색이 모자·가디건에만 칠해진다(`-key` 확인).
- 서브에이전트가 문에서 종종걸음으로 들어와 주인 옆에 줄 선다.
- 브라우저 콘솔 오류 0. 콘솔에서 `officeDebug()` 를 부르면 사람마다 지금 자세(`pose`)가 나온다.
